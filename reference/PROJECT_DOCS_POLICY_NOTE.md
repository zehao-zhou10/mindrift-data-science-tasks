# Project Docs Policy Note

If you want maximum compliance consistency, paste your full official project guidelines into a local file in this repo (for your own reference), then keep this checklist alongside it.

Recommended files (all under `reference/`):
- `PROJECT_GUIDELINES_FULL.md` (paste full official text manually)
- `DATA_SCIENCE_SIMPLIFIED_GUIDE.md`
- `PROMPT_SPEC_TEMPLATE.md` (generic; copy or add `PROMPT_SPEC_<task>.md` per task folder)
- `HUMAN_EXPLANATION_CHECKLIST.md`
- `AI_ALLOWED_SCOPE.md`

Current stance used in this repo:
- AI support is used only for Step 2 Python code and code-side ideation.
- Prompt and human-readable explanation remain human-authored.
- Code must be deterministic and use only allowed libraries.
- Task should map to a plausible real-world data science workflow.
