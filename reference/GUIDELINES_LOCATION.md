# Guidelines & reference layout (all tasks)

Everything shared across tasks lives in this folder **`reference/`**:

- `PROJECT_GUIDELINES_FULL.md` — paste full official project guidelines (canonical).
- `DATA_SCIENCE_SIMPLIFIED_GUIDE.md` — DS-focused working checklist.
- `AI_ALLOWED_SCOPE.md` — what AI may vs must not help with.
- `HUMAN_EXPLANATION_CHECKLIST.md` — structure for your human-written explanation.
- `PROMPT_SPEC_TEMPLATE.md` — generic prompt-spec checklist (copy/adapt per task).
- `PROJECT_DOCS_POLICY_NOTE.md` — how to keep docs in sync.

Workspace root has a short `README.md` pointing here.

Per-task folders should only hold **task-specific** artifacts (code, data, `PROMPT_SPEC_<task>.md`, `final_human/` drafts).
